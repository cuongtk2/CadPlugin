# 🇻🇳 CadPlugin — Bộ công cụ tự động hóa AutoCAD

Chào mừng bạn đến với kho lưu trữ các tiện ích mở rộng (Plugins) và lệnh tự động hóa AutoCAD do **CuongTK2** phát triển.

## 📦 Danh sách Plugins / Lệnh hiện có
### 1. SplitScreen
* **Mô tả:** Lệnh AutoLISP giúp tự động chia đôi màn hình làm việc, đưa AutoCAD sang nửa trái và File Explorer sang nửa phải chỉ với một cú gõ lệnh.
* **Cách dùng:** Gõ `SPLITSCREEN` trực tiếp trong dòng lệnh của AutoCAD.

#  CadPlugin — AutoCAD Automation Toolset

Welcome to the repository of plugins and automation commands for AutoCAD developed by **CuongTK2**.

## 📦 Available Plugins / Commands
### 1. SplitScreen
* **Description:** An AutoLISP command that automatically snaps AutoCAD to the left half of the screen and File Explorer to the right half with a single command-line entry.
* **Usage:** Type `SPLITSCREEN` directly in the AutoCAD command line.
